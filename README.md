# Check the agent's call

An unofficial design concept by Gaurav Basantani for Overwatch Data: a fraud case shown as a timeline, with the evidence the agent used right next to its suggested decision, so a bank analyst can confirm or override in under a minute. It is not affiliated with Overwatch Data, and the bank, people, case and numbers are made up and simplified. Live page: https://gauravbasantani.github.io/overwatch-concept/
